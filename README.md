This is a sample dataset prepared for the paper "DCMD-SC: A smart contract-enabled decentralized scheme for cigarette manufacturing data storage, tracing, sharing, and integrity verification".

This dataset contains desensitized actual manufacturing data extracted from the official production system of Shifang Cigarette Factory, China Tobacco Sichuan Industrial Co., Ltd. All sensitive information has been stripped or anonymized to comply with enterprise data privacy regulations and industry norms.

The data accurately reflects the core metadata of cigarette master-case production and is consistent with real-world production scenarios. It serves as a reliable experimental basis for verifying the feasibility and performance of the DCMD-SC scheme proposed in our research.

We guarantee the authenticity and reliability of the dataset, as it is derived from formal industrial production processes without artificial fabrication. Researchers are welcome to use this dataset for academic research on industrial data management, blockchain applications, and related fields, while abiding by relevant academic ethics and data usage specifications.
